UCW PIN Wallet

Create a PIN-secured user-controlled wallet. The server returns a challenge; the browser runs sdk.execute; then the app lists the wallet address and balances. Uses @circle-fin/user-controlled-wallets and @circle-fin/w3s-pw-web-sdk.

After you have a wallet:

  • Continue asks the server for a fresh userToken and lists available wallets.
  • Reset changes a PIN you know.
  • Recover is for a forgotten PIN.

Wallets:

    Enter a user ID and create a wallet (challenge → wallet).
