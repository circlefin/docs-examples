UCW Social Wallet

Create a user-controlled wallet with Google login. After sign-in, the server returns a challenge; the browser runs sdk.execute; then the app lists the wallet address and balances. Uses @circle-fin/user-controlled-wallets and @circle-fin/w3s-pw-web-sdk.

First login: initialize challenge → wallet. Later logins: already initialized — list wallets only (no challenge).

Wallets:

    Click Login with Google (challenge → wallet on first login).
